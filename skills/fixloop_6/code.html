visibility ปรับขนาดตัวหนังสือใหญ่พิเศษ + คอนทราสต์สูง
VERSION 02 • ELDERLY & ACCESSIBILITY STATES

ชุดสถานะระบบ (โหมดผู้สูงอายุ)

ออกแบบโดยเน้นตัวอักษรขนาดใหญ่พิเศษ ไอคอนขนาดใหญ่ คอนทราสต์ 7:1 (AAA) และปุ่มกดสัมผัสกว้าง ไม่ซับซ้อน

1. กำลังโหลดข้อมูล (Loading)

กำลังทำงาน
hourglass_top

ระบบกำลังค้นหาข้อมูลของคุณ...

กรุณารอสักครู่ เครื่องกำลังติดต่อกับเจ้าหน้าที่เขต ไม่ต้องกดปุ่มใด ๆ ซ้ำ

กำลังอ่านข้อมูล: รายการแจ้งซ่อมไฟส่องสว่างและท่อระบายน้ำ
สำหรับผู้สูงอายุ: มีข้อความเตือนชัดเจนไม่ให้ตกใจหรือกดซ้ำ ระดับเสียง: มีเสียงแจ้งเตือนเบา ๆ

2. เกิดข้อผิดพลาด (Error)

ติดขัดชั่วคราว
warning

ไม่สามารถเปิดหน้านี้ได้ในขณะนี้

อินเทอร์เน็ตอาจจะหลุด หรือระบบกำลังปรับปรุง
ไม่ต้องกังวล ข้อมูลของคุณยังไม่หาย

สำหรับผู้สูงอายุ: หลีกเลี่ยง Error Code ซับซ้อน มีปุ่มโทรศัพท์ฉุกเฉินชัดเจน

3. ไม่มีข้อมูล (Empty)

ไม่มีรายการค้าง
task_alt

ยังไม่มีเรื่องร้องเรียนในละแวกนี้

ในบริเวณชุมชนของคุณ ปัญหาทั้งหมดได้รับการแก้ไขเรียบร้อยแล้ว หรือยังไม่มีผู้แจ้งเรื่องใหม่เข้ามา

สำหรับผู้สูงอายุ: แนะนำขั้นตอนต่อไปด้วยปุ่มสีน้ำเงินขนาดใหญ่สัมผัสง่าย

4. ดำเนินการสำเร็จ (Success)

ส่งเรื่องสำเร็จ
check_circle

ส่งเรื่องร้องเรียนเรียบร้อยแล้ว!

เจ้าหน้าที่เขตได้รับเรื่องของคุณแล้ว จะเริ่มลงพื้นที่ตรวจสอบในวันทำการ

รหัสประจำเรื่องของคุณคือ:
#FL-7F3A2K
ท่านสามารถจดรหัสนี้ไว้สอบถามเจ้าหน้าที่ได้
สำหรับผู้สูงอายุ: รหัสสั้น ชัดเจน อ่านออกเสียงง่าย พร้อมปุ่มกลับบ้าน
