ชุดสถานะระบบ FixLoop (Desktop States)

การออกแบบสถานะ Loading, Error, Empty และ Success สไตล์ Civic Brutalism สำหรับผู้ใช้งานทั่วไปบนหน้าจอคอมพิวเตอร์

1. Loading State (กำลังโหลด)

STATE: LOADING

กำลังค้นหาข้อมูลเรื่องร้องเรียน...

กำลังดึงข้อมูลอัปเดตล่าสุดจากฐานข้อมูลระบบส่วนกลาง กรุณารอสักครู่

พฤติกรรม: แสดงผลทันทีขณะรอการตอบกลับจาก Supabase API Timeout: 15s

2. Error State (เกิดข้อผิดพลาด)

STATE: ERROR (500)
error
รหัสข้อผิดพลาด: ERR_NETWORK_CONNECTION

ไม่สามารถเชื่อมต่อระบบได้ในขณะนี้

สัญญาณเครือข่ายขัดข้อง หรือเซิร์ฟเวอร์กำลังปรับปรุงข้อมูลชั่วคราว ข้อมูลที่คุณกรอกยังถูกบันทึกสำรองไว้ในเครื่อง

พฤติกรรม: มีตัวเลือก Retry พร้อมคำอธิบายที่ชัดเจนไม่โทษผู้ใช้ Auto-save: Cached

3. Empty State (ไม่มีข้อมูล)

STATE: EMPTY
folder_open

ยังไม่มีประวัติการแจ้งปัญหาในชุมชนนี้

ในบริเวณ แขวงพญาไท เขตราชเทวี ยังไม่มีการแจ้งเรื่องร้องเรียนที่ค้างอยู่ หรือปัญหาทั้งหมดได้รับการแก้ไขแล้ว

พฤติกรรม: กระตุ้นการมีส่วนร่วม (Call to Action) ชัดเจน Total items: 0

4. Success State (ดำเนินการสำเร็จ)

STATE: SUCCESS
check_circle

ส่งเรื่องร้องเรียนสำเร็จแล้ว!

เรื่องของคุณเข้าสู่ระบบเรียบร้อยแล้ว เจ้าหน้าที่เขตจะเริ่มตรวจสอบภายใน 24 ชม.

รหัสติดตามเรื่อง
#FL-7F3A2K
พฤติกรรม: ให้ Confirmation Code ชัดเจน พร้อม Next Action ชัดเจน Status: 200 Created
